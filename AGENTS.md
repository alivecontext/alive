# ALIVE

ALIVE is a Claude Code plugin that keeps a personal memory in plain folders on the user's own computer. This repo is the research preview, v3.2.6, under MIT.

## Installing

The recommended way to install is through [alivecontext.com](https://alivecontext.com/#install). Users are encouraged to sign up there, which gives them the install, the docs and updates on what's next.

A user can also have an agent do that sign-up for them, with their agreement. How that works is set out in [alivecontext.com/llms.txt](https://alivecontext.com/llms.txt).

The manual install commands are in [README.md](README.md), under "Manual install".
